## 🌐 Live Status Engine & UI Overview

🖥️ [COMPUTER EMPIRE] ────► 🛠️ Custom Rig Configurator ────► ⚡ Real-Time Store Status Engine


> **Computer Empire** is a high-octane, dark-mode storefront designed for custom PC enthusiasts, esports pros, and workstation builders. Built with utility-first Tailwind CSS, responsive SVG graphics, and a real-time JavaScript status engine.

---

## 🔥 Key Features

| Feature | Description |
| :--- | :--- |
| 🟢 **Live Store Status Engine** | Calculates store opening/closing hours dynamically (`10:30 AM - 8:00 PM`) using local system time with active ping animations. |
| 🎨 **Cyberpunk Dark Aesthetics** | Engineered with deep void colors (`#050505`), custom radial glows, and neon cyan accents. |
| 📱 **100% Fully Responsive** | Seamless layout adaptation from mobile viewports up to 4K Ultra-wide displays with a slide-out drawer menu. |
| 🏎️ **Interactive Hardware Cards** | Showcases Nvidia RTX GPUs, AMD Ryzen X3D CPUs, DDR5 Memory, and Liquid Cooling setups. |
| 📍 **Instant Navigation CTA** | One-click Google Maps integration & direct phone dialing links for immediate customer conversion. |

---

## 🛠️ Tech Stack & Technologies Used

- **Markup:** `HTML5` (Semantic Architecture)
- **Styling:** `Tailwind CSS (CDN)` with custom theme configuration
- **Typography:** `Plus Jakarta Sans` & `Rajdhani` (Google Fonts)
- **Logic / Scripting:** Pure Vanilla `JavaScript` (DOM Manipulation, Time Math, Dynamic Status Engine)
- **Visual Assets:** Micro-inline SVGs (Zero external image dependencies for instant load speed)
